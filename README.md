# Password_generator
Password Generation: Generate secure passwords with customizable length (8 to 32 characters) and strength levels (Low, Medium, Strong).  Clipboard Integration: Instantly copy generated passwords to your system clipboard with a single click.  Credential Storage: Securely save your website usernames and passwords locally into an encrypted-format text file (info.txt).  View Saved Credentials: Easily retrieve and print all stored login entries directly from the interface.  Tech Stack Language: Python 3  GUI Framework: tkinter, tkinter.ttk  Utilities: pyperclip, random, os
